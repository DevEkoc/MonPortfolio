# Prompt pour Charte Graphique - Portfolio Moderne

Créez une charte graphique complète pour un site portfolio professionnel avec les spécifications suivantes :

## 1. Palette de Couleurs

Développez une palette basée sur **le bleu comme couleur primaire** et **le jaune orangé comme couleur d'accent**, en utilisant la nomenclature Tailwind CSS (50 à 950).

### 1.1. Couleur Primaire (Bleu)
- Générez 11 nuances de bleu (50 à 950)
- Le niveau 500 sera utilisé pour les éléments interactifs et focus
- Le niveau 600 sera la couleur principale pour boutons et liens actifs
- Le niveau 800-900 pour les textes importants en mode sombre

### 1.2. Couleur d'Accent (Jaune Orangé)
- Créez 11 nuances de jaune orangé (50 à 950)
- Le niveau 400-500 pour les éléments de mise en valeur
- Le niveau 100 pour les fonds de badges/tags
- Le niveau 600-700 pour les liens et éléments actifs

### 1.3. Couleurs Neutres (Gris)
- Palette complète de gris (50 à 950)
- Niveau 50 : fond des sections en mode clair
- Niveau 400 : texte secondaire
- Niveau 800 : fond des cartes en mode sombre
- Niveau 900 : fond des sections en mode sombre
- Niveau 950 : fond principal du body en mode sombre

### 1.4. Système de Thèmes
**Mode Clair :**
- Fond principal : blanc ou gris très clair
- Texte principal : gris très foncé
- Texte secondaire : gris moyen
- Bordures : gris clair

**Mode Sombre :**
- Fond principal : gris très foncé (950)
- Fond secondaire : gris foncé (900)
- Texte principal : gris très clair
- Texte secondaire : gris moyen clair
- Bordures : gris foncé

## 2. Dégradés et Effets Visuels

### 2.1. Dégradés Principaux
- **Titre hero et logo** : dégradé linéaire du bleu primaire vers le jaune orangé
- **Arrière-plans subtils** :
  - Mode clair : du gris 50 vers gris 100
  - Mode sombre : du gris 950 vers gris 900
- **Effets de halo** : dégradé bleu vers jaune orangé avec flou pour les images

### 2.2. Ombres et Profondeur
- Ombres légères pour les cartes au repos
- Ombres plus marquées au survol
- Utilisation des niveaux d'élévation cohérents

## 3. Typographie

### 3.1. Hiérarchie Typographique
Définissez une échelle typographique responsive :
- **H1 (Titre principal)** : très grande taille, responsive, gras
- **H2 (Titres de section)** : grande taille, responsive, gras, espacement serré
- **H3 (Titres de cartes)** : taille moyenne, gras
- **Corps de texte** : taille confortable pour la lecture
- **Texte secondaire** : plus petit, pour les légendes et métadonnées

### 3.2. Propriétés
- Police principale : sans-serif moderne
- Police secondaire : monospace pour le code
- Antialiasing activé
- Responsive à tous les breakpoints

## 4. Composants d'Interface

### 4.1. Boutons
**Bouton Primaire :**
- Fond : bleu primaire (600)
- Texte : blanc
- États : hover, focus, active, disabled
- Transitions fluides

**Bouton Secondaire :**
- Fond : gris clair (mode clair) / gris foncé (mode sombre)
- Texte : adaptatif au thème
- Bordure optionnelle

### 4.2. Cartes (Cards)
- Coins arrondis moyens à grands
- Ombres subtiles
- Bordures fines
- Fond adaptatif au thème
- Effets au survol (ombre + légère échelle)
- Transitions fluides

### 4.3. Formulaires
- Champs avec coins arrondis
- Bordures adaptatives au thème
- Focus avec anneau de couleur primaire
- États de validation (succès, erreur)

### 4.4. Navigation
- Position sticky ou fixe
- Arrière-plan translucide avec effet de flou
- Indicateur de page active
- Menu mobile responsive

## 5. Layout et Espacement

### 5.1. Grille et Conteneurs
- Largeur maximale cohérente
- Padding responsive
- Grilles adaptatives (1, 2, 3, 4 colonnes selon la taille d'écran)

### 5.2. Espacement Vertical
- Sections avec padding généreux
- Espacement cohérent entre les éléments
- Utilisation de l'échelle d'espacement standard

## 6. Animations et Micro-interactions

### 6.1. Principes d'Animation
- Animations déclenchées au scroll
- Effet d'échelonnement pour les listes
- Transitions rapides pour les couleurs
- Animations de transformation avec physique naturelle

### 6.2. Animations Communes
- **fadeInUp** : apparition en fondu + translation
- **scale** : grossissement au survol
- **hover effects** : élévation et ombres pour les cartes
- **focus states** : anneaux de couleur primaire

## 7. Responsive Design

### 7.1. Breakpoints
- Mobile first
- Adaptation fluide entre tous les breakpoints
- Tailles de police, espacements et grilles responsive

### 7.2. Éléments Adaptatifs
- Navigation qui se transforme en menu burger sur mobile
- Grilles qui passent de 1 à plusieurs colonnes
- Tailles de texte qui s'adaptent
- Espacements qui se réduisent sur mobile

## 8. Accessibilité

- Contrastes suffisants pour tous les thèmes
- Focus visible sur tous les éléments interactifs
- Animations respectueuses des préférences utilisateur
- Textes alternatifs et structures sémantiques

---

**Instructions d'implémentation :**
1. Utilisez Tailwind CSS pour toutes les classes
2. Implémentez le dark mode avec les classes `dark:`
3. Testez tous les contrastes pour l'accessibilité
4. Assurez-vous que tous les composants fonctionnent dans les deux thèmes
5. Optimisez pour les performances et la maintenabilité
