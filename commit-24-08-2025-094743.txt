feat(frontend, backend): Formulaire de contact complet, correction bug critique & amélioration UX (Phase 11)

Ce commit finalise la phase 11 avec la mise en place complète du formulaire de contact, la correction d'un bug bloquant côté front, et une amélioration UX importante.

Backend (Phase 11) :
- Modèle `ContactMessage` pour stocker les messages de contact.
- Serializer et vue API REST (`ContactMessageSerializer`, `ContactMessageCreateView`).
- Endpoint sécurisé `/api/v1/contact/` avec gestion du honeypot (anti-spam) et throttling.
- Enregistrement des messages en base MySQL.

Frontend (Phase 11) :
- Composant React `ContactForm` avec validation Zod (nom, email, message, honeypot, etc.).
- Gestion des erreurs de validation côté client et serveur (affichage inline).
- Intégration Axios pour l'appel à l'API backend.
- Affichage d'un message de succès ou d'erreur après soumission.
- **Nouveau** : Le message de succès disparaît automatiquement après 4 secondes (UX améliorée).
- Correction du bug critique : "Cannot read properties of undefined (reading 'find')" lors de la soumission (gestion robuste des erreurs Zod/Axios).
- Respect du mode sombre, responsive, et design moderne/minimaliste.

Tests & vérifications :
- Test manuel complet du formulaire (soumission, validation, gestion des erreurs, UX).
- Vérification du bon enregistrement des messages côté back-end.
- Contrôle du respect des règles de sécurité (CORS, honeypot, throttling).

Bilan :
- Le formulaire de contact fonctionne parfaitement (front ↔ back).
- L'expérience utilisateur est fluide et professionnelle.
- Le code respecte les conventions du projet (séparation logique/UI, typage, etc.).
